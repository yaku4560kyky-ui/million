Ⅰ

ゲーム進行の手順

1ハンドの開始準備からポット授与・次ハンド開始までの標準フロー

STEP 0

テーブル準備・カード確認

ハンド前
  1. デッキの枚数確認（52枚／ジョーカー除外）。新品開封時はフェイスアップで4スート×13ランクを必ず確認。
  2. ウォッシュ（スクランブル）：テーブル上で円を描くように混ぜ、前ハンドの並びを完全に崩す。
  3. リフルシャッフル×2 → ストリップ → リフル → カットの順を毎ハンド徹底。
  4. カットはカットカードで行い、ボトムカードが見えないように当てる。
  5. 手・カードは常にプレイヤーから見えるテーブル上の位置に保つ。膝上・テーブル下に下ろさない。
目的：シャッフルの「型」を固定し、イカサマ疑義とトラブルを未然に防ぐ。手順を省略しない。
STEP 1

ボタン移動・ブラインド徴収

プリフロップ前
  1. ディーラーボタンを時計回りに1つ移動。位置を見える形で確定。
  2. SB（$5）をボタン左隣から徴収しベットラインへ。
  3. BB（$10）をその左隣から徴収。ストラドルは宣言の正当性とBB位置を確認のうえ受理。
  4. 欠席席・ミスドブラインドはブラインドを強制的に徴収する。離席扱いになっていない場合もブラインドを徴収する。
STEP 2

ホールカード配布

配牌
  1. SB（ボタン左隣）から時計回りに、1枚ずつ2周配る。2枚まとめ配りはしない。
  2. カードはテーブルに伏せて滑らせ、低く・速く・一定の力で。浮かせて配らない。
  3. 配布中に露出（フリップ）したカードはミスディール対象。手を止めて裁定（後述）。
  4. 配り終えたら残りデッキをマック手前のセット位置へ。
ミスディールの主な条件：①配牌前の枚数不足判明 ②ボタン位置の誤り ③配布順の誤り ④2枚以上の露出。アクションが進む前の発覚は再配（リディール）。
STEP 3

プリフロップ・アクション管理

第1ベッティングラウンド
  1. アクションはUTG（BB左隣）から時計回りに開始。手番を明確に指し示す。
  2. 各アクションを口頭で復唱・確認（「コール$10」「レイズ$30まで」）。曖昧な動作は口頭確認。
  3. ベット・レイズ額はベットライン手前にまとめて置かせ、カウントしてから確定。
  4. 1周してアクションが揃い、全員のベット額が一致したらラウンド終了を宣言。
  5. 各ベットをポットへ集約。集約時に額の不一致がないか最終確認。
STEP 4

フロップ（バーン1＋3枚）

第2ベッティングラウンド
  1. バーンカード1枚を伏せたままマック手前へ。バーンとボードは混ぜない・重ねない。
  2. 3枚を一旦伏せてまとめて引き、横一列にめくって同時公開（1枚ずつチラ見せしない）。
  3. ポストフロップはボタン左隣の生存最先席から時計回りに開始。
  4. チェック continuation は最後の席まで確認、ベットが入れば一巡して額を揃える。
STEP 5

ターン／リバー（各バーン1＋1枚）

第3・第4ラウンド
  1. 各ストリートで必ずバーン1枚の後にボードへ1枚追加。
  2. ボードカードはバーンの右側に等間隔で並べ、5枚が一直線に揃うよう配置。
  3. オールインでアクションが残らない場合は、ハンドを公開させてからランナウト。
  4. 複数オールインはサイドポットを正確に作成してからボードを進める。
STEP 6

ショーダウン・ハンド判定

勝敗確定
  1. ショーダウン順：リバーの最終アグレッサーから時計回りに公開。全員チェックならボタンに近い席から。
  2. ディーラーが役を声に出して読み上げ（「フラッシュ、Aハイ」等）客観的に確定。
  3. ホール2枚＋ボード5枚の計7枚からベストファイブを構成。自己申告ではなくカードで判定（cards speak）。
  4. チョップはキッカーまで比較。端数チップはポジション基準のハウスルールで配分。
  5. 勝者確定まで敗者のマックもすぐには回収しない（誤判定確認のため一拍置く）。
裁定の原則：表向きに出た手は口頭申告と異なってもカードの役で判定。伏せたままマックに触れた手は原則デッド。
STEP 7

ポット授与・次ハンド準備

クロージング
  1. レーキを先に取り分けてから（後述基準）、残りを勝者へプッシュ。
  2. 勝者へ渡す前にポットを崩して額面を見せる（目視確認できる状態に広げる）。
  3. 全カード（ボード・バーン・マック）を回収しデッキを再構成。
  4. ボタンを進めてSTEP 1へ。停滞させず一定のテンポで回す。
Ⅱ

ディーラー注意点

トラブル・疑義・チップ事故を防ぐ運用上の鉄則

◈ チップ・ポット管理

  • ポットのチップは常に広げておく。額面ごとに見やすく展開し、誰でも目視できる状態に。
  • ポット額を尋ねられても答えない（ノーリミット）。「ご自身でご確認ください」と返し、カウント・宣言しない。
  • 各ベットは一旦手前に置かせて確認してからポットへ集約。先に混ぜない。
  • オールイン額は必ず声に出してカウントし対象額を明示。
  • サイドポットはメイン／サイドを物理的に分けて配置し対象者を取り違えない。

♤ カード管理

  • ボードとバーンは絶対に重ねない。バーンは専用位置へ。
  • デッキ・ボトムカードを露出させない。配布中も伏せて低く滑らせる。
  • フロップ3枚は同時公開。先読みさせない。
  • 露出カードが出たら手を止め申告してから裁定。独断で配り直さない。
  • マックに触れたカードは戻さない。デッドはデッド。

⟳ アクション・進行管理

  • 手番を明示し、アウトオブターンを誘発させない。
  • すべてのアクションを復唱・確認。無言ベットは口頭確認。
  • ストリングベット（分割追加）を許さない。一動作で出させるか額を先に宣言させる。
  • レイズ額が最低額に満たない場合は受理可否を裁定（後述）。
  • 長考にはタイム宣言。迷う裁定は独断で進めずフロアを呼ぶ。

¥ 金銭・チップ授受

  • 持ち込み・両替・追加バイインの履歴を明確化（卓の運用に従う）。
  • プレイヤー間のチップ直接授受（チップダンピング）を防止。盤外移動を見逃さない。
  • テーブルから出したチップは原則場に戻せない（テーブルステークス）。
  • レーキは規定どおり正確に。取り過ぎ・取り忘れをしない。

⊘ 中立性・態度

  • プレイの助言・示唆をしない。「降りた方が」等は厳禁。
  • 役の有利不利・確率について聞かれても答えない。
  • 特定プレイヤーへの表情・反応の偏りを出さず常に等距離。
  • 常連・高額プレイヤーにも裁定基準を一律適用。

☂ セキュリティ・事故防止

  • テーブル上に常に手を見せ不自然な動作をしない。
  • カード・チップのテーブル外への持ち出しを監視。
  • カードを置きっぱなしの離席に注意喚起。
  • 疑義・苦情が出たらハンドを停止し進行を凍結してから対応。

プレイヤーマナー裁定一覧

ディーラーが注意・裁定を取るべきマナー違反と対応の標準

状況・マナー違反内容ディーラーの裁定・対応
ストリングベットString Betチップを一度の動作で出さず継ぎ足してベット／レイズする行為。最初に出した額のみ有効。継ぎ足し分は戻させる。事前に額を口頭宣言していれば宣言額が有効。「一度に出すか、額を先に言ってください」と案内。
アクション順違反Out of Turn自分の手番でないのにアクションしてしまう。原則先行アクションは保留。手番が回ったとき前段に変化がなければ拘束、変化があれば任意のアクション可。注意喚起する。
口頭宣言の拘束Verbal is Binding手番中に「コール」「レイズ」等を声に出した／額を宣言した。手番中の明確な口頭宣言は拘束力を持つ。撤回不可。チップ未投入でも宣言額を履行させる。
最低レイズ未満Incomplete Raiseレイズ額が直前レイズ幅の最低額に達していない。オールインでない限り正規額までの増額を求めるかコール扱いに訂正。オールイン時の再レイズ権の有無は卓ルールで裁定。
スプラッシュ・ザ・ポットSplash the Potチップをポットへ直接投げ入れ額が確認不能になる。禁止。ベットは自分の前に整然と置かせる。額不明時は本人とテーブルで確認のうえ確定。
カードのマック（誤放棄）Mucked Hand降りていないのに伏せたままマックへ送る／触れる。原則そのハンドはデッド。識別不能になれば権利消失。
カード露出Exposed Cardホールカードを意図的／不意に他者へ見せる。故意の露出は注意・警告。配布段階のディーラー起因の露出は所定手順で処理。プレイ中の自己露出は本人責任。
スローロールSlow Roll勝ち確定なのにわざとゆっくり見せて相手を焦らす。マナー違反として注意。速やかな公開を促す。常習は責任者へ報告。
ワンプレイヤー・パーハンドOne Player to a Hand第三者に相談する／助言を受ける。禁止。進行中の相談・コーチング、観戦者の口出しを制止。
共通言語English Only進行中、他者が理解できない言語でハンドについて会話。テーブルで共通言語の使用を促す。ハンドに関わる会話は特に制止。
曖昧動作手の動き・チップ移動がチェックかベットか判別できない。口頭確認で意図を確定。テーブルを叩く＝チェックを明確に。疑義時はフロア裁定。
カード場外移動ホールカードをテーブル外へ持ち出す／高く持ち上げる。カードは常にテーブル上で扱わせる。持ち出しは即制止。
アングルシュートAngle Shootingルールの隙を突き相手を誤認させる行為。意図的なら強く注意し状況を凍結してフロア裁定。再発時は厳格化。
時間超過（長考）過度な長考で進行を著しく停滞させる。他プレイヤーまたはディーラー判断でタイム（クロック）宣言。時間内に行動なければフォールド扱い。
チップダンピングChip Dumping特定相手へチップを移す不自然なプレイ・授受。監視・制止。盤外での直接授受は不可。疑わしければ責任者へ即報告。
ショーダウン申告誤り役を誤って申告する／見せ渋る。カードが示す役で判定（cards speak）。開かれた手は申告と異なっても正しい役で裁定。
共通原則：迷ったら独断で進めずハンドを止めてフロア（責任者）を呼ぶ。裁定は誰にも一律。注意は淡々と、テーブル全体に基準が見える形で行う。

レーキ取り扱いの手順

  1. ポット確定後、勝者へプッシュする前にレーキを取り分ける。
  2. レーキ額は最小デノミ$5・切上げで計算（例：算出43点 → 45点）。
  3. 通常卓はキャップなしでレーキ率10%をそのまま適用。
  4. ハイレート卓は$100に達したらそれ以上取らない（上限$100）。
  5. 取り分けたレーキは所定位置に明確に分けて置き、ポットと混同しない。
計算例（通常卓・10%）：ポット$430 → レーキ$43 → 最小デノミ$5・切上げで$45。キャップなしのため率どおり徴収。
Ⅴ

早見：禁止・徹底事項

迷ったときに立ち返る要点

✕ やってはいけない

  • ポット額を答える（ノーリミットでは厳禁）
  • プレイへの助言・確率の示唆
  • ポットを山積みにしたまま放置
  • ボードとバーンを重ねる・混ぜる
  • フロップを1枚ずつめくる
  • シャッフル手順の省略
  • 裁定を独断で強行
  • 常連だけ基準を緩める

✓ 常に徹底する

  • ポットのチップは広げて見せる
  • 各ストリートで必ずバーン1枚
  • アクションは復唱・確認
  • 手番を明示する
  • 手は常にテーブル上に見せる
  • ハンドはcards speakで判定
  • 授与前にポットを崩して額面確認
  • 迷ったらフロアを呼ぶ
